# Innovatives Framework: Next.js

## Auswahl
Für die Umsetzung von Planorama wurde das Framework **Next.js** gewählt.

## Begründung
- Moderne, performante Webentwicklung
- Server-Side Rendering für schnelle Ladezeiten
- Gute Integration mit React
- Umfangreiche Community und viele Ressourcen
- Skalierbarkeit für zukünftige Erweiterungen
